# speed-test

Замерялка скорости интернета с этого компьютера. Принимает адрес тяжёлого файла, последовательно
скачивает его несколько раз (по умолчанию 10), дожидается каждого ответа целиком и печатает среднее
время запроса, объём скачанного и скорость в МБ/с.

## Что нужно поставить

**uv** — он сам поднимет Python и зависимости. Установка в PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Python 3.13 отдельно ставить не обязательно: если его нет, выполните `uv python install 3.13`.
Зависимости тоже ставить не нужно — `uv run` сам создаст окружение по `pyproject.toml` и `uv.lock`.

## Запуск

Из папки проекта:

```bash
uv run speed-test
```

Без аргументов берётся тестовый файл на 10 МБ: `https://speed.cloudflare.com/__down?bytes=10000000`.
Свой адрес — первым аргументом:

```bash
uv run speed-test https://example.com/big-image.jpg
```

Параметры:

- `-n`, `--requests` — сколько сделать запросов, по умолчанию 10.
- `--timeout` — сколько секунд ждать ответ, по умолчанию 10.
- `--no-color` — не подсвечивать вывод.

Справка: `uv run speed-test --help`.

## Вывод

Результат идёт в стандартный вывод, сообщения об ошибках — в поток ошибок. Поэтому
`uv run speed-test > result.txt` сохранит замер в файл, а ошибку покажет на экране.

Ключевые цифры подсвечены. Цвет включается только когда вывод идёт в терминал: при записи в файл или
в конвейер утилита печатает чистый текст. Отключить подсветку вручную можно флагом `--no-color` или
переменной окружения `NO_COLOR`.

## Как читать вывод

```
Адрес:    https://speed.cloudflare.com/__down?bytes=10000000
Запросов: 3, таймаут: 30 с

 1/3: 9.54 МБ за 0.30 с — 31.47 МБ/с
 2/3: 9.54 МБ за 0.20 с — 47.59 МБ/с
 3/3: 9.54 МБ за 0.22 с — 42.43 МБ/с

Итог:
  среднее время запроса: 0.22 с
  скачано всего:         28.61 МБ
  средняя скорость:      42.87 МБ/с
  разброс по запросам:   от 27.32 МБ/с до 67.15 МБ/с

Значения двоичные: 1 МБ = 1024 × 1024 байт. Провайдер измеряет канал в десятичных мегабитах
(1 Мбит = 1 000 000 бит).
Скорость в единицах провайдера: 44.95 МБ/с (359.6 Мбит/с)
```

- **Всё, что выше последних двух строк, — двоичное**: 1 МБ = 1024 × 1024 байт. Так же считает размеры
  проводник Windows.
- **Последняя строка — десятичная**, в единицах провайдера: 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000
  бит. С тарифом сравнивайте именно её, там указаны мегабиты.
- Двоичную скорость нельзя просто умножить на 8, чтобы получить мегабиты: основания разные, множитель
  выходит 8.39. Поэтому пересчёт и печатается отдельной строкой.
- **Средняя скорость** — весь объём, делённый на всё время, а не среднее скоростей: иначе один
  короткий быстрый запрос весил бы столько же, сколько длинный медленный.
- **Разброс** показывает, ровный ли канал: большая разница между минимумом и максимумом значит, что
  мешает что-то ещё — соседняя загрузка, Wi-Fi, нагрузка на сервер.

## Что стоит знать о замере

- **Берите тяжёлый файл**, хотя бы несколько мегабайт. На мелком измеряется задержка сети, а не
  пропускная способность — утилита предупредит об этом отдельной строкой.
- **Первый запрос обычно медленнее** остальных: в него попадают DNS и TLS-рукопожатие. Дальше
  соединение переиспользуется, поэтому меряется именно скачивание.
- **Замер честен ровно настолько, насколько быстр сервер.** Вы меряете канал до конкретного хоста:
  если он далеко или перегружен, цифра будет ниже скорости вашего интернета.
- Запросы идут с заголовком `Cache-Control: no-cache`. Промежуточный CDN всё равно может ответить из
  своего кеша — тогда это скорость до ближайшего узла, а не до исходного сервера.
- **Не всякая ссылка подойдёт.** Часть хостов (например, Wikimedia) закрывается от автоматических
  клиентов или ограничивает повторные скачивания одного файла — придёт 403 или 429. Берите тестовые
  файлы, зеркала дистрибутивов или свой сервер.

## Ошибки

Любая ошибка прекращает прогон и даёт код возврата 1: среднее по неполным данным вводит в заблуждение.
Утилита объясняет, что произошло:

| Что случилось | Сообщение |
| --- | --- |
| Имя хоста не разрешается | Хост … не найден: имя не разрешается |
| Хост не принимает соединение | Не удалось подключиться к …: хост недоступен или соединение блокируется |
| Сертификат не прошёл проверку | Не удалось установить защищённое соединение с … |
| Ответ не пришёл вовремя | Ответ от … не пришёл за N с |
| Файла по адресу нет | Сервер ответил 404 |
| Хост закрыт от автоматических клиентов | Сервер ответил 403 |
| Хост ограничил частоту запросов | Сервер ответил 429 |
| Соединение оборвалось при скачивании | Соединение с … оборвалось во время скачивания |
| Ответ пустой | По этому адресу нечего скачивать |

Параметры проверяются до первого запроса, код возврата 2. Сообщение говорит, что исправить:

```
$ uv run speed-test "speed.cloudflare.com/__down?bytes=10000000"
Адрес без схемы: speed.cloudflare.com/__down?bytes=10000000
Допишите протокол в начало, например: https://speed.cloudflare.com/__down?bytes=10000000

Все параметры: speed-test --help
```

Так же разбираются чужая схема (`ftp://`), нечисловое или нулевое число запросов и неположительный
таймаут.

## Что внутри

- `speed_test.py` — весь код.
- `pyproject.toml`, `uv.lock` — зависимости и их зафиксированные версии.
- `.python-version` — версия Python для uv.
- `.venv/` — окружение, которое создаёт uv; в репозиторий не нужно.
